
# UNSEEN — Creative Studio Website

A modern, immersive creative studio website built with React and Vite. Designed with bold typography, a refined dark aesthetic, and visually engaging project showcases to create a distinctive digital experience.

This is an original implementation inspired by the mood and interaction patterns of immersive creative-studio websites. It is not affiliated with Unseen Studio and does not use its proprietary source code or assets.

## ✨ Features

- Modern, minimal creative studio design
- Responsive layouts for desktop, tablet, and mobile
- Interactive visual elements and custom CSS artwork
- Creative project showcase for photography and video editing
- Bold typography and dark editorial aesthetics
- Reusable React components
- Lucide React icons
- Fast development and optimized production builds with Vite

## 🛠️ Tech Stack

- **Frontend:** React
- **Build Tool:** Vite
- **Language:** JavaScript (ES Modules)
- **Styling:** CSS3
- **Icons:** Lucide React
- **Markup:** HTML5

## 🚀 Getting Started

### Prerequisites

- Node.js (LTS recommended)
- npm
- Git

### Installation

Clone the repository:

```bash
git clone <YOUR_REPOSITORY_URL>
```

Navigate to the project directory:

```bash
cd unseen-inspired-creative-studio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the website.

## 🏗️ Production Build

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

The optimized production files will be generated in the `dist/` directory.

## 🎨 Customization

- **Projects:** Update project names, categories, descriptions, tags, and image paths in `src/main.jsx`.
- **Styling:** Customize colors, typography, layouts, animations, and responsive breakpoints in `src/styles.css`.
- **Artwork:** Replace placeholder visuals with original photography, video thumbnails, or other creative assets.
- **Branding:** Update the studio name, logo, contact email, and social media links.
- **Content:** Adapt the project showcase and sections to match your studio's requirements.

## 🌐 Deployment

The website can be deployed using Vercel, Netlify, or another static hosting platform.

### Vercel Configuration

| Setting | Value |
|---|---|
| Framework Preset | Vite |
| Build Command | `npm run build` |
| Output Directory | `dist` |
| Install Command | `npm install` |

Connect your Git repository to Vercel and deploy the project. Enable Git integration for automatic deployments on future pushes.
