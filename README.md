# UNSEEN-inspired creative studio website

A responsive React + Vite concept site inspired by the mood and interaction patterns of immersive creative-studio websites. This is an original implementation with CSS-generated artwork and placeholder project concepts; it is not affiliated with Unseen Studio and does not use their proprietary source code or assets.

## Run locally

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
npm run preview
```

## Customize

- Edit project names, categories and descriptions in `src/main.jsx`.
- Replace CSS-generated project visuals in `src/styles.css` with your own images or 3D assets.
- Update the contact email and social links in `src/main.jsx`.
